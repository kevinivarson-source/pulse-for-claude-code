# Starter pack

The tracks every Pulse player opens with, so there is something to hear before you record anything.

Each `.pulse` file is one recording in the plugin's own format (see the main README). The player cuts each one into tracks with the Auto rules, and also offers it whole under Raw recordings. `index.json` lists the recordings in the order they appear.

These first recordings are generated by [`tools/make-starter.mjs`](../tools/make-starter.mjs). They follow the rhythm of typical Claude Code sessions: tool timings, thinking pauses, parallel calls, subagents, permission prompts and idle breaks.

## Add a real session

Real sessions are welcome as pull requests. Pick one from `~/.claude/pulse` on your computer, then before you send it:

1. Replace the project name on the first line with a title (letters, digits and dashes).
2. Rename any connector tools (`mcp__yourcompany__...`) to something neutral, such as `mcp__db__run_sql`.
3. Add it to `index.json` with an `id` starting with `starter-`, its `file`, a `title` and one line of `about`.

A recording holds no prompts, code or file names, only event codes, tool names and times.
