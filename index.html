    Already set up?

    On your own player, type your key or paste a pairing link. You can also scan the code shown on a device that's already paired.

    Add another device

    Scan with your phone or tablet camera, then tap "Add to Home Screen" to install Pulse like an app.

    Connect Claude Code

    Copy this setup and paste it into Claude Code on any computer. Claude installs the plugin and connects it to this player.
